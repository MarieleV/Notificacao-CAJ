### Configuração do Ambiente Front-end

Para inicializar a interface do usuário, abra o terminal de sua preferência, acesse o diretório correspondente ao front-end e execute as etapas a seguir:

```bash
# Navegação até o diretório da aplicação visual
cd front-end

# Instalação das dependências e pacotes declarados
npm install

# Inicialização do servidor de desenvolvimento
npm run dev

```

Por padrão, a aplicação estará disponível para acesso local através do endereço `http://localhost:5173` (porta padrão do ambiente de desenvolvimento Vite).

> **Nota:** Certifique-se de que o ambiente back-end esteja em execução prévia ou devidamente configurado para que todas as chamadas assíncronas de API, emissão de pareceres e processamentos da inteligência artificial funcionem corretamente.
